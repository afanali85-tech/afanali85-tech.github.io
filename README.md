# Dr. Afan Ali — Academic Website

Responsive, dependency-free static website ready for GitHub Pages.

## Publish
1. Create a public GitHub repository named `afanali85-tech.github.io` under the `afanali85-tech` account (or use any repository name for a project site).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Visit `https://afanali85-tech.github.io/` (or the project's Pages URL).

## Before publishing
- Replace the `AA` portrait placeholder with an authorized professional photo.
- Replace `REPLACE_WITH_EMAIL` with the correct public contact email.
- Verify manuscript titles, authors, publication status, and add DOI/Google Scholar links.
- Add verified industrial employers, job titles, dates, degrees, and awards from the CV.
- Confirm the current job title and preferred biography wording.

No frameworks or build commands are required.
